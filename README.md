### ALGO-000037: Superpolynomial depth-two threshold lower bounds
- **Subfield:** Boolean circuit and formula complexity
- **Open:** Give an explicit polynomial-time computable function requiring superpolynomially many gates in a threshold-of-threshold circuit, \(\mathrm{THR}\circ\mathrm{THR}\).
- **Status:** Open despite substantial lower bounds for restricted threshold architectures and stronger depth restrictions. General polynomial-size depth-two threshold circuits remain poorly understood.

- **Why:** Establishes limitations of a simple but expressive neural-style architecture.
